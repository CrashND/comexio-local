# Changelog

## 0.1.0 - 2026-11-02

- Eigenstaendiges HA-Custom-Integration-Paket mit GUI-Konfiguration und Options-Flow.
- 16 dokumentierte Licht-Relaisausgaenge als ein Katalog.
- Batch-GET via TCP Port 1505 mit konfigurierbarem Intervall.
- Sichere Voreinstellung: read-only Binary Sensors.
- Opt-in: direktes SET mit anschliessender GET-Statusbestaetigung.
- Einzelverbindung pro Anfrage; serialisierte Requests; keine automatischen COMEXIO-Konfigurationsaenderungen.
- Diagnostik und Offline-Tests.
